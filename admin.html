Add, edit and unpublish your dispatches — no code required.

How publishing works on this site. The site is now real separate files: index.html, one HTML file per article under /articles/, and articles.js that index.html reads to build the homepage. This page lets you edit that content and download the files that changed.
  1. Add or edit articles below.
  2. Click Export updated files — it downloads a .zip containing the updated articles.js and a fresh HTML file for every article.
  3. Upload those files to your host, in the same folder structure (articles.js at the root, each article inside /articles/) — overwrite what's there.
Deleted articles won't remove their old file from your host automatically — delete that file manually after uploading if you unpublish something.
